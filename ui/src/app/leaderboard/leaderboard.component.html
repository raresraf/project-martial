Gemini 2.5 Pro (r=1) — Full Threshold Analysis {{ proR1Expanded ? '▲' : '▼' }}

Each snippet was augmented by Gemini 2.5 Pro, then each individual comment block (r=1) was embedded by USE into a 512-d vector. Similarity equals the symmetric average coverage of matched blocks at the given cosine threshold. Evaluated on 3,126 pairs. Best configuration overall.
