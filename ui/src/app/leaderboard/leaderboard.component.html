Complexity-Based Birthmarks — Full Threshold Analysis {{ birthmarksExpanded ? '▲' : '▼' }}

Evaluated on ~280,000 pairs of C++ Codeforces submissions (2/3 similar, 1/3 not similar). The model uses 9 profiling metrics (branch-misses, branches, context-switches, cpu-migrations, cycles, instructions, page-faults, stalled-cycles-frontend, task-clock), each approximated by a 4-feature regression regressor, yielding a 36-dimensional birthmark. Only 24 of the 36 weights are non-zero after training.

Precision and Recall are for the similar class. F1 is the weighted average across both classes. The highlighted row marks the optimal threshold (best weighted F1).

Gemini 2.5 Pro — Full Threshold Analysis (r=1) {{ proExpanded ? '▲' : '▼' }}

Each code snippet in CoSiM was augmented by Gemini 2.5 Pro with dense semantic documentation, then embedded by the Universal Sentence Encoder (USE) in windows of r concatenated comment blocks. Similarity is a coverage metric: the fraction of comment lines in each program matched by at least one USE embedding from the other (cosine ≥ threshold), averaged symmetrically.

Results below are for r=1 (best Pro configuration). Metrics are macro-averaged over the balanced CoSiM classes; the highlighted row marks the optimal threshold (best macro F1). Evaluated on 3,126 successfully augmented pairs.

Gemini 2.5 Flash — Full Threshold Analysis (r=6) {{ flashExpanded ? '▲' : '▼' }}

Same pipeline as Pro using Gemini 2.5 Flash for augmentation. Results below are for r=6 (best Flash configuration). Evaluated on 1,823 successfully augmented pairs. The Flash model exhibits a narrower operating range: at low thresholds the model predicts all pairs as similar (near-zero not-similar F1), then rises sharply around t≈0.55 to a peak near t=0.62.

Submit Results

We welcome submissions from researchers benchmarking models on the CoSiM dataset. Evaluate your model against the CoSiM dataset and open an issue or pull request on Project Martial's GitHub repository with your results — best F1, precision, recall, accuracy, FPR, and the optimal threshold configuration used.

Please include the full threshold sweep that produced the reported numbers so results are reproducible and comparable to existing baselines.
