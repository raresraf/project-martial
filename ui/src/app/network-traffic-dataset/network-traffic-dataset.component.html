Network Traffic Dataset

A corpus of application-layer network traffic captured between standard database clients and MySQL, PostgreSQL, and SQL Server engines running in Docker and Google Cloud SQL environments. Similarity is computed as cosine distance over TF-IDF vectors of byte-level n-grams, with best discrimination achieved at 4-grams.

Key findings:
  • Same-engine comparisons consistently yield 4-gram similarity ≥ 0.61 regardless of version.
  • Cross-engine 4-gram similarities: MySQL vs PostgreSQL ≈ 0.03–0.06; MySQL vs SQL Server ≈ 0.22–0.27.
  • PostgreSQL 14+ shows a drop in similarity vs earlier versions due to SCRAM-SHA-256 authentication adopted by the standard client.
  • Cloud SQL deployments score slightly lower vs Docker images of the same version, reflecting cloud-specific greeting packet modifications.
  • 4-grams outperform 2-grams and 3-grams at cross-engine discrimination while maintaining high intra-engine similarity.
